Chat plans, database authorization, and individual dataset unlocks are managed separately. A Chat subscription does not grant access to every commercial database. Queries involving free data still count toward Chat usage.

## Databases, versions, and system models

Open the database selector below the composer. Commercial and free databases are listed separately. Search by name, select a database, and expand its versions and system models.

You can choose multiple versions. System model options reflect the selected versions. Confirm your choices before submitting a query. Changing them does not rewrite earlier results.

## Restricted data

Candidate names, sources, and links remain available while restricted values are hidden. Open the dataset details to check access, available unlock options, and remaining credits. Unlock options may differ between datasets.

## Top up, then unlock a dataset

When credits are insufficient, **Get unlock credits** opens the purchase page. A top-up adds credits; it does not automatically unlock the current dataset.

Return to the original conversation and use **Refresh access** to check the balance. To access a specific dataset, select **Unlock dataset** and confirm the displayed credit cost. Refresh the details after access is granted.

## Free databases

When a free-search tool is available, Cortex can look for relevant free data and list it separately in the conversation with its source. It checks the product, intended use, and process, and explains differences such as region or system boundary. Unrelated data should not be presented as a substitute.

Free data does not use dataset unlock credits, but the query still counts toward Chat usage. Free results are not necessarily equivalent to restricted data and do not automatically change your database selection.

Use the account and purchase pages for the current database list, access options, and prices rather than a fixed database count or an old price in this guide.
