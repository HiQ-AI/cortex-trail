Cortex Chat helps you find life cycle datasets, check their applicability, and discuss LCA questions. Sign in to [Chat](/chat) and choose **New Task**, or continue a conversation from the sidebar.

## First use

New accounts without conversation history or an existing profile can choose their role, industry, current focus, and LCA experience. Expand **Other** when the choices do not fit. You can go back to revise a choice or skip a step.

Review your choices and decide whether to save them to your profile. **Fill in example** puts an editable question in the composer; it does not send it. You can change or remove the example.

## Choose sources

Use the database button below the composer to select databases, versions, and system models. You can select multiple versions of a database. Available system models update with the selected versions.

Selecting a commercial database does not grant access to its values. See [Databases and data access](/guides/database-licensing).

## Describe the query

Write the product, intended use, process, and region in Chinese or English. For example:

> Find LLDPE granulate production data for material inputs to plastic film production, preferably for China.

If you need a finished product, name it rather than just its material. Cortex may ask for missing conditions; returned candidates still need checking.

## Read the results

Candidates and dataset links appear in the conversation. Open a link to check the product, region, unit, system model, and description. Values that are restricted or could not be read cannot be used as calculation inputs.
