Cortex Cowork is the desktop application. These guides cover installation, database access, and calculation engines.

## Install

Cowork ships as a native app for macOS, Windows, and Linux. Download the latest build for [macOS](https://download.hiq.earth/latest/Cortex-arm64.dmg), [Windows](https://download.hiq.earth/latest/Cortex-Setup.exe), or [Linux](https://download.hiq.earth/latest/Cortex-x64.AppImage). Install does not require a login; database search and cloud sync do.

## Where to go next

- **Connecting a database** — which databases are free, which are licensed, and how to turn one on. See [Connecting a database](/guides/cowork/database-licensing).
- **Running a full calculation** — from BOM to impact assessment in Cowork. See [Running a calculation](/guides/cowork/running-a-calculation).
